第 0 章：它到底做什么

一句话：帮你的文章自动写出「搜索结果里显示的标题和摘要」，并把它放进网页源码，让搜索引擎和社交平台能读到。

它做的事情

1

你在文章编辑页点一个按钮

2

插件把文章标题和正文发给 AI

3

AI 返回 SEO 标题、描述、关键词、社交分享文案

4

你点保存

5

这些内容被写进网页源码的 <head> 里

它不做的事情

  • 不会改动你的正文，一个字都不会动
  • 不会在前台网页上显示任何界面——访客完全看不到它的存在
  • 不会替你发布文章、不会自动运行（只有你点按钮才动作）

前台网页上看不到它，是正常的。想确认它生效，要看网页源码（见第 5 章）。

第 1 章：安装

免费版

1

后台左侧 → 插件 → 安装插件

2

点顶部 「上传插件」

3

选择 xish-ai-seo-meta.zip → 点「现在安装」

4

装完点 「启用」

Pro 版（可选）

必须先装好并启用免费版，否则 Pro 装了也不会工作。

1

后台 → 插件 → 安装插件 → 上传插件

2

选择 xish-ai-seo-meta-pro.zip → 安装 → 启用

第 2 章：第一次使用前的配置

只需要做一次。

1

后台 → 设置 → AI SEO Meta（也可以在插件列表页，直接点插件下方的 「设置」 快捷链接）

2

填写三项：

字段填什么
API Key从你选择的 AI 服务商后台复制的密钥。不要带 Bearer 前缀，不要有空格或换行
API 端点见下方示例表格
模型名称见下方示例表格
3

语言保持默认「自动」即可

4

点 「保存更改」

常用服务商填写示例

服务商端点模型名
LongCathttps://api.longcat.chat/openai/v1/chat/completionsLongCat-2.5-Preview
OpenAIhttps://api.openai.com/v1/chat/completionsgpt-4o-mini
DeepSeekhttps://api.deepseek.com/v1/chat/completionsdeepseek-chat

任何兼容 OpenAI Chat Completions 格式的服务都能用。具体地址与模型名以服务商官方文档为准，上表仅供参考。

关于费用：插件本身免费，但调用 AI 会产生费用，由你使用的服务商按量计费。只有你点生成时才产生请求。

第 3 章：日常怎么用（最重要）

正确顺序只有一条：先保存，再生成，生成后还要再保存。

1

写好文章标题和正文（或打开一篇已有文章）

2

点右上角 「保存草稿」 或 「发布」 —— 这一步不能省。插件读取的是数据库里已保存的内容，你在编辑器里打了字但没保存，插件读不到

3

右侧栏找到 「AI SEO Meta」 面板，点 「用 AI 生成」

4

等几秒到十几秒，四个框会被自动填满

5

再点一次右上角 「保存草稿」 或 「更新」

四个框分别是什么

字段作用要不要手填
SEO 标题浏览器标签、搜索结果里的蓝色标题，建议 60 字内不用，AI 自动生成；想改可以改
SEO 描述搜索结果标题下面那段摘要，建议 160 字内不用，AI 自动生成
焦点关键词这篇主打的关键词，3–5 个，用逗号分隔不用，AI 自动生成
社交分享文案分享到社交平台时用的文案不用，AI 自动生成

千万别把生成的内容复制进正文。 那是给搜索引擎看的元数据，放进正文会让文章变得莫名其妙，对 SEO 反而有害。

哪些地方可以用

  • 文章
  • 页面
  • 主题自带的公开内容类型（例如 OneNav 主题的「网址」「APP」「书签」「公告」等）

第 4 章：面板在哪里、找不到怎么办

位置：文章或页面的编辑页，右侧栏最底部，在「插件」分组下面。新版 WordPress 的右侧栏默认是收起的，需要你先点开。

按这个顺序排查

1

点编辑器右上角那个方形侧栏图标（在「保存」左边），把右侧栏打开

2

右侧栏顶部有两个标签：「页面/文章」 和 「区块」——点前者（名字是你正在编辑的内容类型）

3

在这个标签里滚到最下面，找「插件」分组，展开就是「AI SEO Meta」

4

如果还是没有：按 Ctrl + Shift + R 强制刷新页面（不是普通 F5）

面板偶尔"消失"通常是浏览器缓存了旧的编辑器脚本。硬刷新即可，插件本身没有问题。

面板可以折叠：点面板标题栏最右边的小箭头就能收起，WordPress 会记住你的选择。

第 5 章：怎么确认它真的生效了

1

确认文章是已发布状态（草稿在前台打不开，无法验证）

2

前台打开这篇文章（点编辑页的「查看文章」，或访问文章链接）

3

按 Ctrl + U 查看网页源代码

4

按 Ctrl + F 搜索 description

你应该看到

<title>你生成的 SEO 标题</title>
<meta name="description" content="你生成的 SEO 描述">
<meta name="keywords" content="你生成的关键词">
<meta property="og:title" content="你生成的 SEO 标题">
<meta name="twitter:card" content="summary">

判断标准

  • <title> 是你生成的 SEO 标题 ✓
  • description 只有一条（插件会自动清掉主题重复输出的，正常结果就是 1 条）✓
  • 内容与你在后台看到的一致 ✓

第 6 章：常见问题

点生成后报错 401

原因：API Key 不对或已过期。

处理：去服务商后台重新复制一个 Key，回到「设置 → AI SEO Meta」，把 Key 框清空后重新粘贴（不要带 Bearer 前缀、不要有空格或换行），保存后重试。

报错 cURL error 28（超时）

原因：端点填错，或你的服务器连不上该地址。

处理：核对端点地址是不是和模型服务商匹配。常见错误是改了模型名、却忘了改端点（比如用 LongCat 的模型名，端点却还留着 OpenAI 的地址）。

生成出来的是「自动草稿」「内容正在编辑完善中」这类占位话

原因：你还没有点保存。新建文章在数据库里叫「自动草稿」、正文是空的，AI 只能编出这类话。

处理：先写好真实标题和正文 → 点保存 → 再点生成。

我在前台看不到任何效果

按顺序检查：

  1. 文章是不是草稿？草稿前台打不开，必须发布
  2. 生成后有没有再点一次保存？不保存数据只在网页表单里，不会进数据库
  3. 看的是不是网页源码（Ctrl+U）？面板内容不会显示在页面上
我装了 Yoast 或 Rank Math，前台看不到插件生成的内容

这是正常的，是刻意设计的。 同一个网页只能有一套 SEO 标签，检测到专业 SEO 插件后，本插件会自动让位，交给它们输出。

想让数据生效，两条路：

  1. 停用 Yoast / Rank Math → 本插件恢复输出
  2. 用 Pro 版 的「对接 SEO 插件」功能，把生成的内容写进 Yoast / Rank Math 的字段（见第 7 章）
文章很短，生成的内容却在瞎编

AI 会基于有限的正文做合理外推。正文太短（比如只有一句话）时，生成的内容可能与文章关联度不高。建议正文写够再生成，描述才准确。

面板上的内容和前台源码不一致

说明你生成后没有点保存。数据库里存的还是上一次保存的内容。点一次「更新」即可。

第 7 章：Pro 版额外功能

前提：免费版已安装并启用。
入口：后台 → 设置 → AI SEO Meta Pro

7.1 批量生成

1

打开「批量生成」标签

2

选择语言（默认「基础版本」即可）

3

勾选要生成的文章（可点「全选」）

4

点 「批量生成」

5

页面会出现进度条，逐篇处理并显示每一篇的结果

重要：每篇文章需要调用一次 AI 接口，约 10–15 秒一篇。处理过程中不要关闭页面。中途某一篇失败不会影响其他篇，失败原因会单独列出。

7.2 多语言

为同一篇文章分别生成中文和英文的标题与描述。

  • 选「中文」：写入默认字段 + _zh 专用字段
  • 选「英文」：只写入 _en 字段，不会覆盖中文内容

已知限制：英文版本目前不会输出到前台网页，只有中文/基础版本会输出。如果需要英文内容生效，请用下面的「对接 SEO 插件」功能，或等待后续版本支持。

7.3 历史回填

扫描已发布但还没有 SEO 元数据的旧文章，一键批量补全。用法与批量生成相同：勾选 → 点按钮 → 看进度条。

7.4 对接 SEO 插件（Rank Math / Yoast）

把已生成的内容直接写入专业 SEO 插件的字段，省去手动复制。

  • Rank Math：写入 rank_math_title / rank_math_description
  • Yoast SEO：写入 _yoast_wpseo_title / _yoast_wpseo_metadesc

使用条件：站点上必须已安装并启用对应的 SEO 插件，否则会提示「未检测到」。

写入后，前台由 Rank Math / Yoast 自己输出。它们可能还需要你完成一次初始设置向导才会开始输出。

第 8 章：Pro 版常见问题

批量生成会不会超时？

不会。批量生成采用逐篇异步处理，一次请求只处理一篇文章，不受服务器单次执行时间限制。文章再多也不会中途整体失败，你还能看到进度和失败明细。

批量生成跑到一半关掉页面会怎样？

已经生成的文章已经保存，不会丢。剩下的文章需要重新勾选再跑一次（已生成过的可以不用再勾）。

装了 Pro 但批量生成提示「未检测到免费版」

说明免费版没有启用。去插件列表确认 Xish AI SEO Meta（免费版） 处于启用状态。

Pro 的多语言英文版前台看不到

这是当前版本的已知限制，英文内容只写入了独立字段、前台不输出。请用「对接 SEO 插件」功能，或等待后续版本。

对接 SEO 插件后前台还是没变化

检查两点：

  1. Rank Math / Yoast 是否真的启用了
  2. 它们自身是否完成了初始设置（新装的 Rank Math 需要走一次设置向导才会开始输出）

附：常见术语

术语意思
meta 标签写在网页源码 <head> 里的说明信息，访客看不见，搜索引擎会读
端点（Endpoint）AI 服务的网址地址
模型具体用哪个 AI 模型，比如 LongCat-2.5-Preview、gpt-4o-mini
草稿 / 已发布草稿前台打不开，只有发布后访客才能访问
源码网页的 HTML 原始内容，浏览器里按 Ctrl+U 查看
